# Skill: explain_signal

The `rationale` must name the specific feature(s) that drove the signal:

- which moving-average crossover, breakout, or volume spike
- which headline (quoted briefly) and its sentiment
- which fundamental ratio crossed which threshold

If `driver="news"`, surface the headline verbatim (≤ 120 characters). If `driver="mixed"`, list at most three contributing features in order of weight.
