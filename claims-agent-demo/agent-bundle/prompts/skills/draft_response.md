# Skill: draft_response

Draft a response that is safe to send after human review.

Response requirements:

- acknowledge the issue in plain language
- summarize the next operational step
- mention required documents if anything is missing
- keep compensation language conditional
- cite policy source IDs if compensation is discussed

Never write:

- "approved"
- "guaranteed"
- "we will reimburse you" without a human-approval qualifier
- legal conclusions or regulatory promises
