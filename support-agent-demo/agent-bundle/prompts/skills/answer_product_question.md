# Skill: answer_product_question

Answer product questions with the minimum necessary account context.

Guidance:

- Use plan or feature entitlement information when it materially changes the answer.
- Distinguish between what the product does today and what might require an upgrade or human follow-up.
- If a question depends on a live incident, check status before answering.
- If you do not have a supporting source, say that you cannot confirm it.
